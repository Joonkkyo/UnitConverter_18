## STEP 1 — 주제 (1문장)

**프로토타입 `UnitConverter.py` 를 ECB·OCP/SRP에 맞는 테스트 가능 인터페이스로 분해하고, Logic/UI Dual-Track TDD 경계를 확정한다.**

---

## STEP 2 — 아키텍처 (ECB)

```
┌─────────────────────────────────────────┐
│  boundary                                │
│  input.parse / validate                  │
│  output.format (table|json|csv)        │
│  config_loader (P2)                      │
└─────────────────┬───────────────────────┘
                  ▼
┌─────────────────────────────────────────┐
│  control                                 │
│  flow.run_conversion                     │
└─────────────────┬───────────────────────┘
                  ▼
┌─────────────────────────────────────────┐
│  entity                                  │
│  constants (SSOT)                        │
│  registry (등록·조회)                     │
│  converter (to_base / from_base / all)   │
└─────────────────────────────────────────┘
```

| 원칙 | 적용 |
|------|------|
| **SRP** | 파싱 ≠ 검증 ≠ 환산 ≠ 포맷 ≠ 흐름 |
| **OCP** | 새 단위 = `register_unit` · converter 분기 추가 없음 |
| **DIP** | control은 entity **포트** 호출 (구체 registry 주입 가능) |
| **단방향** | boundary → control → entity |

## STEP 5 — OCP 설계 (단위 확장)

### Before (프로토타입)

```python
if unit == "meter":
    meter_value = value
elif unit == "feet":
    meter_value = value / 3.28084
# ...
```

### After (목표)

```python
base = to_base(unit, value)          # registry 조회
results = convert_all(unit, value)   # list_units() 순회
```

| 확장 시나리오 | 변경 지점 |
|--------------|-----------|
| cubit 추가 | `register_unit("cubit", 0.4572)` 만 |
| JSON 설정 | `load_units_from_file` → register 반복 |
| converter.py | **수정 없음** (목표) |
